## Cómo consultar estas referencias

Para una tarea visual específica de un mundo, consulta únicamente su guía y su ficha. Úsalas para mantener la identidad cromática, el estilo de ilustración, la ambientación, los materiales, las texturas, las composiciones y la continuidad de personajes y símbolos, además de evitar que los mundos pierdan diferenciación. Una tarea técnica no relacionada no necesita cargar las diez referencias.

Estas fuentes cumplen funciones distintas:

- La **dirección artística** define cómo se representa visualmente el mundo y sirve como referencia creativa; no modifica por sí sola código ni recursos aprobados.
- `theme.yaml` es la fuente técnica de los tokens, colores y opciones de interfaz que Fatebound puede aplicar.
- Un paquete `.fateworld` es un contenedor de datos no confiables, sometido a su contrato, validación e instalación; una guía artística no forma parte automáticamente de ese contrato.
- Las **mecánicas jugables** pertenecen al motor y a las reglas versionadas de cada mundo; no se deducen de una guía visual.

La documentación artística tampoco autoriza cambios automáticos en mundos instalados ni sustituye el canon, la dirección narrativa o el estado de aprobación expresado en cada guía.
